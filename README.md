# LOGICA-COMPUTABILIDAD

Proyecto Integrador Final de **Programación y Análisis de Datos en Python**.

## Componentes
- Módulo I: nómina, persistencia en `nomina.txt`, `with` y manejo de excepciones.
- Módulo II: análisis del inventario con NumPy.
- Módulo III: visualización con Matplotlib y exportación de gráficos PNG.

## Ejecución
```bash
pip install -r requirements.txt
python main.py
```

La base de datos se encuentra en `data/inventario.xlsx`. Los resultados gráficos se guardan en `graficos/`.

## Datos
La base contiene 28.140 registros de inventario y 9 variables. El análisis usa los campos `Centro` y `Valor`, y considera media, mediana, mínimo, máximo, desviación estándar y una proyección del 5%.
